OpenClaw Command & Control via Prompt Injection

Researchers demonstrated how an indirect prompt injection embedded in a webpage could make OpenClaw execute a malicious script, poison future agent context, and behave like a command-and-control agent.

Why this record has no ERS

This AIDEFEND SecureFlow record converts MITRE ATLAS case study AML.CS0051 into a defense-mapped attack flow. It documents the observed attack path and the applicable AIDEFEND controls, but it does not establish one bounded assessed deployment with a configuration, a complete evidence set, and measured control performance. Assigning IVP, ORP, ACI, or ERS values would invent system-specific evidence. The attack steps, ATLAS technique references, and the exact upstream defense set are retained as candidate evidence routes only.

Classification: Validated Research · source date 2026-05-08
