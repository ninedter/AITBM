LLMSmith: RCE Vulnerabilities in LLM-Integrated Applications

Researchers identified 20 remote code execution (RCE) vulnerabilities across 11 different LLM frameworks. They discovered applications deployed on the public internet built using these LLM frameworks and demonstrated the RCE vulnerabilities could be exploited using prompt injection. The 11 LLM frameworks the researchers evaluated were: LangChain, LlamaIndex, Pandas-ai, Langflow, Pandas-llm, Auto-GPT, Griptape, Lagent, MetaGPT, vanna, and langroid.

Why this record has no ERS

This AIDEFEND SecureFlow record converts MITRE ATLAS case study AML.CS0052 into a defense-mapped attack flow. It documents the observed attack path and the applicable AIDEFEND controls, but it does not establish one bounded assessed deployment with a configuration, a complete evidence set, and measured control performance. Assigning IVP, ORP, ACI, or ERS values would invent system-specific evidence. The attack steps, ATLAS technique references, and the exact upstream defense set are retained as candidate evidence routes only.

#StepATLAS tactic / technique
1Analyze LLM Framework APIs for RCEThe researchers performed a static analysis on the APIs of target LLM frameworks to identify functions that execute code from either user input or the response from an LLM and are thus vulnerable to RCE.AML.TA0003
AML.T0017
2Find Deployed LLM Framework AppsThe researchers performed targeting to identify applications that are likely built with LLM Frameworks and may use the functions vulnerable to RCE. This was done by scanning source code repositories for app deployment URLs.AML.TA0002
AML.T0004
3Extract Vulnerable Call ChainsThe researchers ran their static analysis to extract call chains from target application's source code to identify those that utilize LLM framework functions vulnerable to RCE.AML.TA0008
AML.T0084.003
4Craft RCE-Triggering PromptsThe researchers developed prompts to trigger tool invocations that lead to RCE.AML.TA0003
AML.T0065
5Target Public AI Agent AppsThe researchers targeted public-facing applications that expose an AI agent to user input as a means to execute their prompts.AML.TA0004
AML.T0049
6Submit Direct Prompt InjectionThe researchers directly prompted the AI agent with their malicious instructions.AML.TA0005
AML.T0051.000
7Bypass Guardrails with JailbreakFor target applications where the AI agent refused the researcher's request, they used lightweight jailbreaking strategies to bypass the LLM's guardrails.AML.TA0007
AML.T0054
8Invoke Vulnerable Agent ToolsThe researchers' prompts called the AI agent's tools, targeting call chains that can lead to code execution.AML.TA0012
AML.T0053
9Execute Code in Python InterpreterThe code included in the researcher's prompts was executed in a sandboxed Python interpreter.AML.TA0005
AML.T0050
10Escape Interpreter SandboxThe researchers included code escape techniques designed to bypass any limitations a sandbox may place on code execution.AML.TA0012
AML.T0105
