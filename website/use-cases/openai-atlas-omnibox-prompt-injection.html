OpenAI Atlas Omnibox Prompt Injection

NeuralTrust showed that a malformed URL-like string in OpenAI Atlas could carry natural-language instructions that fail URL parsing, fall back into prompt mode, and be treated as high-trust user intent. The published demonstration opened an attacker-chosen destination; phishing and destructive authenticated-session actions were described as potential abuse rather than demonstrated outcomes.

Why this record has no ERS

This AIDEFEND SecureFlow record is a curated attack flow built from public research reporting. It documents the demonstrated attack path and the applicable AIDEFEND controls, but it does not establish one bounded assessed deployment with a configuration, a complete evidence set, and measured control performance. Assigning IVP, ORP, ACI, or ERS values would invent system-specific evidence. The attack steps, ATLAS technique references, and the exact upstream defense set are retained as candidate evidence routes only.

Attack steps

#StepATLAS tactic / technique
1Craft URL-Like String With Embedded InstructionsThe attacker prepares a string that visually resembles a URL, begins with URL-like structure, and embeds natural-language instructions after malformed components so the browser will not treat it as a normal navigable URL.AML.TA0003
AML.T0051.002
2Place String Into Atlas OmniboxThe victim copies, pastes, clicks, or otherwise places the crafted string into the OpenAI Atlas omnibox, which is shared between address navigation and agent command entry.AML.TA0005
AML.T0051.002
3Fallback From Failed URL Parse to Prompt ModeBecause the input fails URL validation, Atlas treats the entire string as a prompt instead of refusing ambiguous navigation or requiring an explicit Navigate versus Ask mode choice.AML.TA0005
AML.T0051.000
4Treat Embedded Instructions as Trusted User IntentThe embedded instructions are interpreted as high-trust user intent with fewer safety checks, allowing the attacker text to override the visible navigation intent or safety policy.AML.TA0005
AML.T0051.000
5Open Attacker-Chosen DestinationThe demonstrated payload caused Atlas to follow the injected instruction and open neuraltrust.ai. The source separately describes phishing and destructive authenticated-session actions as possible abuse, not as outcomes shown in the published demonstration.AML.TA0005
AML.T0053
