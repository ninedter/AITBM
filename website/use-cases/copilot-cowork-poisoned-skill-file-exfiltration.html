Cowork Exfil: Poisoned-Skill File Exfiltration via Microsoft 365 Copilot Cowork

PromptArmor demonstrated that five lines of indirect prompt injection hidden in an 81-line Copilot Cowork Skills file can exfiltrate documents from across a Microsoft 365 tenant. When the user asks Cowork to recap their week, the poisoned skill instructs the autonomous agent to read SharePoint and OneDrive files, mint pre-authenticated download links, embed them in HTML image tags, and auto-send a Teams message; sending Teams or Outlook messages to the active user needs no human approval, so opening the message fires the image requests and leaks the links. The attack succeeded on every trial (5/5) against Claude Opus 4.7 and Sonnet 4.6.

Why this record has no ERS

This AIDEFEND SecureFlow record is a curated attack flow built from public research reporting. It documents the demonstrated attack path and the applicable AIDEFEND controls, but it does not establish one bounded assessed deployment with a configuration, a complete evidence set, and measured control performance. Assigning IVP, ORP, ACI, or ERS values would invent system-specific evidence. The attack steps, ATLAS technique references, and the exact upstream defense set are retained as candidate evidence routes only.

Attack steps

#StepATLAS tactic / technique
1Introduce Poisoned Cowork SkillThe attacker authors a Copilot Cowork Skills file that hides five lines of indirect prompt injection inside an otherwise normal 81-line skill, declaring a fake 'document preview' service to be used when building a weekly recap message.AML.TA0003
AML.T0104
2Cowork Loads Skill and Executes Hidden InstructionsWhen the user asks Copilot Cowork to review what they worked on that week, the poisoned skill enters the agent context and its hidden instructions are treated as trusted guidance rather than untrusted data.AML.TA0005
AML.T0051.001
3Read M365 Files via Microsoft Graph ToolsOperating with the user's own Microsoft 365 permissions through Microsoft Graph, Cowork reads SharePoint and OneDrive files that contain PII and financial data to assemble the requested recap.AML.TA0009
AML.T0085.001
4Auto-Send Teams Message Without ApprovalFollowing the injected 'preview service' instructions, Cowork retrieves pre-authenticated download links for each file, embeds them as query parameters in HTML image tags, and sends the recap as a Teams message to the active user; sending Teams or Outlook messages to the user requires no human approval.AML.TA0005
AML.T0053
5Opened Message Fires Data-Bearing Image TagsWhen the user opens the Teams message, the embedded HTML image tags automatically issue network requests to the attacker-controlled site, carrying the pre-authenticated download links in the URL.AML.TA0010
AML.T0077
6Pre-Auth Links Exfiltrate M365 FilesThe attacker logs the inbound requests, extracts the pre-authenticated links, and downloads the PII and financial files from across the Microsoft 365 environment without ever holding the user's credentials.AML.TA0010
AML.T0086
