GTG-1002: Hiding an Espionage Campaign Inside Ordinary Claude Code Tasks

This source is retained for threat and defensive-evidence research, but AITBM does not manufacture a deployment score where no assessable system boundary exists.

Why this analysis has no ERS

The source does not define one assessable AI deployment. The AI service was abused, not compromised: no control of the provider's system is reported as having been measured, bypassed, or held. The victim organizations are conventional enterprises rather than AI deployments, and their outcomes are known only through an attacker's own AI-generated reports, which Anthropic warns are not proof of compromise. Critically, the brief states that its AIDEFEND controls are deployment proposals for AI-service operators and explicitly not claims about Anthropic's implementation, so there is no observed control performance to score at any anchor — every IVP placement would be an inference about an unpublished architecture. The attacker's own orchestration and MCP tool surface are the adversary, not an assessed system. The analysis is preserved with its AIDEFEND routes but carries no ERS.

Classification: Incident · source date 2026-09-08
