PUBLIC-EVIDENCE AI SECURITY CASE STUDY

Copilot for Word Turned a Hidden Prompt into a Document-Borne AI Worm

A white-on-white prompt inside a Word document survived formatting removal, silently changed financial figures, and copied itself into Copilot's newly generated document. The researcher placed JSON-formatted instructions in small white text on a white background; when the document entered a Copilot for Word drafting or editing operation, formatting was stripped before model processing, so the hidden text became model-readable context competing with the user's visible request. Copilot followed the injected instruction and divided financial figures by two, making the security impact document-integrity loss rather than an unwanted reply. The same hidden prompt was written into the output document, so the instruction could run again if that output was later attached, uploaded, or selected as context. The brief is explicit that this is not autonomous network propagation: every hop depends on a user or retrieval process bringing the carrier document back into a Copilot operation. The researcher reported the issue to MSRC on 6 March; Microsoft applied mitigations and model updates in April and July, and the behaviour was still reproduced on 15 July against GPT-5.5 and GPT-5.6 deployments.

ASSESSED SYSTEM

Microsoft Copilot for Word in its drafting and editing operation, as reproduced on 2026-07-15 against GPT-5.5 and GPT-5.6 deployments after Microsoft's April and July mitigations: a source Word document enters the operation, presentation formatting is stripped before model processing, the remaining text competes with the user's visible request, and Copilot writes the resulting document. Representative configuration: any document-assistant operation that removes the presentation layer from an untrusted source file and admits the surviving text into the same context as the user's instruction.

OUT OF SCOPE

The carrier document and the researcher's JSON-formatted hidden instruction are the attack, not the assessed system. The base models are not assessed: GPT-5.5 and GPT-5.6 are recorded as the deployments under which the behaviour reproduced, and the assessment scores the application's instruction/data separation and release controls rather than model obedience. Microsoft's April and July mitigations are in scope only as evidence that a control exists and did not close the class; their internal design is not published and is not assessed. Later Copilot surfaces and other Office applications are out of scope. The researcher did not publish the complete attack prompt and reports no in-the-wild campaign, so no exploitation outcome is scored.

Architecture: Tool-Calling LLM / Connected GenAI (decision tree Q3) — Q1 = NO: a single assistant, no peer agents. Q2 = NO: the operation is user-initiated and request-scoped; the brief is explicit that this is not autonomous network propagation and that every hop depends on a user or retrieval process bringing the carrier document back into a drafting or editing operation. Q3 = YES: the model does not merely return text — the application applies its output to the document and produces a new file, so the model drives a connected application capability. Evidence in the brief: Copilot silently divided financial figures in the document and copied the hidden prompt into the newly generated document. Tier 2: Tier 2 (Consumer): Copilot for Word is a broadly distributed productivity assistant serving a large user population rather than an internal service with controlled clients, and the demonstrated harm — silent alteration of financial figures in a document a person will rely on — lands on that population. Tier is set by the consequence class of the deployment; the controlled-research nature of the evidence is carried by the ACI fidelity factor, not by lowering the tier.

Documented attack or failure path

  1. An attacker places JSON-formatted instructions in small white text on a white background inside an ordinary-looking Word document; a person viewing the page would not normally see them.
  2. The document enters a Copilot for Word drafting or editing operation. Formatting is stripped before model processing, so the hidden text becomes model-readable context and competes with the user's visible request.
  3. Copilot follows the injected instruction and silently divides financial figures by two — an unexplained change to document values that the user's request does not account for.
  4. The same hidden prompt is copied into the newly generated document. If that output is later attached, uploaded, or selected as relevant context for another Copilot operation, the instruction can run again; the carrier propagates through document reuse rather than by searching for victims.

Observed controls and bounded outcomes

Positive credit is given only where the record directly demonstrates a control operating. Recommended or merely presumed controls receive no positive scoring credit.

  • A mitigation layer exists and has been iterated on: the researcher reported to MSRC on 6 March and Microsoft applied mitigations and model updates in April and July. Ro-1 is scored at 0.25 rather than 0.00 on this basis — a control is present and was revised twice, even though the class reproduced on 15 July.
  • The scope of the demonstrated effect stayed inside the document boundary. No connector access, tool invocation, or outbound network transfer is reported, so the exfiltration and tool-authority boundaries are not scored as failures.
  • The brief is explicit that propagation is workflow-dependent and requires a user or retrieval process to reintroduce the carrier, so no autonomous propagation is scored.

WHAT THIS CASE TEACHES

Cp is recorded as the specification default rather than as corroborated, and that distinction is the point of the case. The failure is real and reproducible, but it terminates inside the document: nothing reached a connector, a tool, or the network, and propagation needs a person to carry the file forward. Scoring it at the ceiling on graph-derived merits would have overstated a contained integrity failure as an ungated external cascade.
