TIER 3 · THREAT-DEFENSE PLANNING

COMPASS to AITBM Mapping

Uses COMPASS threat classes to plan AITBM evidence collection without transferring priority or maturity values into scores.

How to use this crosswalk

External requirements, controls, threats, and practices identify evidence to collect or tests to run. Only measured evidence from the assessed deployment determines AITBM rubric placements, IVP, ORP, ACI, MVT findings, and ERS.

Changed-framework carriers reconciled 2026-09-21; stable-framework currency basis carried forward from 2026-09-09. No endorsement by the external framework owner is implied.

COMPASS

Threat-defense planning

OWASP Threat Defense COMPASS · OWASP GenAI Security Project

COMPASS structures threat-defense analysis and prioritization. Its threat classes may select tests, but Likelihood, Impact, OODA records, maturity language, and register priority never write back to an AITBM IVP anchor, ORP dimension, ACI term, pathway, CRM, ERS, or severity.
