How to use this crosswalk

External requirements, controls, threats, and practices identify evidence to collect or tests to run. Only measured evidence from the assessed deployment determines AITBM rubric placements, IVP, ORP, ACI, MVT findings, and ERS.

CSA AI Security

Cloud AI security framework (threat model + controls)

CSA AI Security (MAESTRO + AI Controls Matrix) · Cloud Security Alliance (CSA)

CSA supplies cloud-specific AI security through MAESTRO's seven-layer threat model and AICM v1.1's 247 control objectives across 18 domains. This crosswalk routes CSA evidence into AITBM's IVP, current Aa/As/Cp/Rf operational dimensions, and ACI. A CSA threat, control, domain, or maturity level never has an inherent ERS value or fixed ERS reduction.

Key findings

  • All seven MAESTRO layers and all 18 current AICM domains are routed; this is not a claim that all 247 AICM control objectives have identical targets or have been individually crosswalked.
  • Multi-tenancy, shared services, and agent marketplaces affect As and the System Dependency Graph; they do not set a generic ERS or Cp value.
  • AICM control objectives can route AITBM evidence only when the assessed deployment demonstrates the applicable rubric criterion and test method.
  • AISMM maturity levels provide organizational context and are not converted into IVP, ORP, ACI, or ERS values.
