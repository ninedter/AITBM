AI Data Exposure and Exfiltration Case Studies

AI data exposure cases involving connectors, cross-tenant access, credentials, local files, private prompts, cloud data, and exfiltration paths.

18 matched references · all link to complete source and scoring records

Why this topic matters

AI systems concentrate high-value context and frequently connect private sources to public or attacker-influenced sinks. This collection helps assessors trace whether data minimization, tenant isolation, retrieval authorization, output controls, and audit evidence actually constrain that path.

Tr-3Pr-1Pr-2Pr-3Pr-4Cn-1

Evaluation questions

  • Which private data, credentials, prompts, files, and tenant records can enter the system context?
  • Are retrieval and connector permissions evaluated for the current user and request?
  • Can model output reach URLs, rendered content, logs, tools, or other external sinks?
  • Would audit records prove what data crossed the boundary and which identity authorized it?

Framework routes: OWASP AISVS · CSA AI Security. External frameworks guide threat, control, and evidence selection; measured deployment evidence determines AITBM scores.
