Why this topic matters

An AI system inherits risk from models, datasets, packages, plugins, registries, extensions, prompts, configuration, and hosted services. The cases below show how trusted names and normal developer workflows can become execution or data-theft paths.

Ro-4Tr-3Tr-4Pr-3Cn-1Cn-7

Evaluation questions

  • Are models, dependencies, prompts, tools, and configuration pinned to verified provenance?
  • Can names, registries, update channels, or mutable branches redirect a trusted reference?
  • Does loading an artifact execute code or alter inference behavior before verification?
  • Can the organization reconstruct lineage and contain every affected deployment quickly?

Framework routes: MITRE ATLAS · AIDEFEND. External frameworks guide threat, control, and evidence selection; measured deployment evidence determines AITBM scores.
